# Sports Grow — 주니어 운동선수 성장 관리 플랫폼

사업계획서를 바탕으로 제작한 반응형 데모 웹사이트입니다. 학생, 학부모, 코치, 아카데미·연맹의 네 가지 사용자 계정과 역할별 화면, 서비스 소개 페이지, 그리고 사이트 운영을 위한 관리자 콘솔을 포함합니다.

## 페이지 구성

## 데모 계정

모든 계정의 비밀번호는 `grow1234`입니다. 로그인 화면의 **체험 계정 정보 채우기** 버튼을 사용하면 선택한 역할의 계정이 자동 입력됩니다.

| 역할 | 이메일 | 이동 페이지 |
| --- | --- | --- |
| 학생 | `player@sportsgrow.kr` | `student.html` |
| 학부모 | `parent@sportsgrow.kr` | `student.html` (기록·프로필 읽기 전용 + 응원·코치 요청·갤러리 업로드·본인 댓글 삭제) |
| 코치 | `coach@sportsgrow.kr` | `coach.html` (학생 화면은 읽기 전용 + 갤러리 업로드·댓글·본인 글 삭제) |
| 아카데미·연맹 | `admin@sportsgrow.kr` | `academy.html` |
| 사이트 관리자 | `ops@sportsgrow.kr` | `admin.html` |

역할이 다른 페이지에 접근하면 로그인 화면으로 이동하며, 해당 역할의 계정으로 다시 로그인해야 합니다. 학부모·코치 계정은 학생 대시보드에 접근할 수 있지만 기록·프로필·공개 범위를 수정할 수 없습니다. 학부모는 응원과 코치 요청, 갤러리 업로드·본인 댓글 삭제를 사용할 수 있고, 코치는 갤러리 업로드·댓글·본인 글 삭제를 사용할 수 있습니다.

사이트 관리자 계정은 아카데미·연맹 계정과 별개입니다. 공개 로그인 화면에는 관리자 역할이 노출되지 않으며, 랜딩 페이지 하단 `이용약관 · 개인정보처리방침` 아래의 `관리자 로그인` 링크 또는 `admin-login.html`로만 진입합니다. 관리자 세션이 없거나 다른 역할로 접근하면 `admin-login.html`로 이동합니다.

### 사진·동영상 갤러리

학생 대시보드의 `사진 · 동영상` 섹션에서 훈련·경기 순간을 미디어로 남기고 댓글로 피드백을 주고받습니다.

| 기능 | 학생 | 학부모 | 코치 |
| --- | --- | --- | --- |
| 미디어 업로드 (사진·동영상) | 가능 | 가능 | 가능 |
| 미디어 댓글 작성 | 가능 | 가능 | 가능 |
| 본인이 올린 미디어·댓글 삭제 | 가능 | 가능 | 가능 |
| 다른 사람의 미디어·댓글 삭제 | 불가 | 불가 | 불가 |
| 프로필·기록 수정 | 가능 | 불가 | 불가 |

- 사진은 최대 1280px JPEG로 자동 압축되고, 동영상은 2MB 이하만 업로드할 수 있습니다.
- 갤러리 카드는 왼쪽 25%에 미디어 썸네일, 오른쪽 75%에 작성자·설명·댓글창을 배치해 목록처럼 빠르게 훑어볼 수 있습니다.
- 코치 계정은 학생 대시보드에서 읽기 전용으로 동작하며, 갤러리의 업로드와 댓글만 사용할 수 있습니다.
- 코치 대시보드 사이드바의 `사진 · 동영상` 바로가기로 `student.html#media`에 진입할 수 있습니다.

## 운영 관리자 콘솔

사이트 운영팀을 위한 별도 콘솔입니다. 기존 대시보드의 앱 셸(사이드바·탑바)과 컴포넌트를 재사용하며, 관리자 전용 스타일은 `css/admin.css`, 데이터·렌더링 로직은 `js/admin.js`에 있습니다.

| 메뉴 | 내용 |
| --- | --- |
| 대시보드 | 전체 회원, 이번 달 입금, 미납·연체, 이번 달 훈련 기록 KPI와 월별 입금 추이, 회원 유형 분포, 최근 가입, 처리 필요 항목 |
| 회원관리 | 학생·학부모·코치·아카데미 탭별 목록, 이름·이메일·소속 검색, 상태·요금제 필터, 페이지네이션, 회원 상세 모달, 회원 추가, CSV 내보내기 |
| 데이터 관리 | 학생별·기간별(1/3/6개월) 훈련 세션·시간·출석률·성장 지수, 성장 추이 선 차트, 주간 훈련량 막대 차트, 성장 지표, 최근 훈련 기록, 훈련 CSV |
| 요금 관리 | 전체/월간/연간·청구 월·입금 상태 필터, 청구·입금·미납·연간 비중 KPI, 월별 입금·미납 차트, 입금 상태 즉시 변경, 입금 내역 CSV |
| 공지 · 문의 | 공지 작성·상태 변경·삭제, 1:1 문의 상태 변경, 운영자 활동 로그 자동 기록 |
| 사이트 설정 | 서비스 이름·고객센터·운영자 연락처, 입금 마감일, 자동 갱신 안내, 가입 승인·점검 모드, 데모 데이터 초기화 |

- 회원 상세는 운영자만 열람하며, 상태 변경·회원 추가·CSV 내보내기 등의 작업은 활동 로그에 기록됩니다.
- 요금 상태를 변경하면 KPI·차트·미납 건수와 사이드바 배지가 즉시 갱신되고 `localStorage`에 저장됩니다.
- `데모 데이터 초기화`를 누르면 관리자 키와 함께 단일 원장·학생·코치·아카데미 저장 키가 삭제되고 초기 시드 데이터로 다시 시작합니다.
- 관리자 데이터는 정적 데모 시드 + `localStorage`이며 서버로 전송되지 않습니다.

## 대시보드 화면 전환

- 학생·학부모, 코치, 아카데미 대시보드는 한 페이지를 길게 스크롤하는 대신, 좌측 카테고리를 클릭하면 해당 화면만 표시됩니다. 모바일에서는 하단 탭과 사이드바 메뉴가 같은 방식으로 동작합니다.
- 현재 화면은 상단 브레드크럼과 좌측·하단 메뉴의 활성 표시로 확인할 수 있으며, 주소 끝의 해시(`student.html#media`, `academy.html#reports`)로 특정 화면을 바로 열 수 있습니다.
- 학생 화면의 `개인 프로필`은 별도 화면이 아니라 `메인` 화면 안에 이어집니다. 내부 링크로 이동할 때는 해당 화면을 먼저 연 뒤 위치로 스크롤합니다.
- 사이트 관리자 콘솔(`admin.html`)은 기존과 동일하게 자체 화면 전환 방식을 사용합니다.

## 실행 방법

정적 HTML/CSS/JS 사이트이므로 별도 빌드가 필요 없습니다. 로컬 서버로 여는 것을 권장합니다.

```powershell
# 프로젝트 루트에서 (Python이 있는 경우)
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/`을 엽니다. VS Code의 Live Server 확장을 사용해도 됩니다.

> `index.html`을 직접 열어도 대부분 동작하지만, 브라우저에 따라 `file://` 환경의 저장소 동작이 달라질 수 있어 로컬 서버 사용을 권장합니다.

## 데모 데이터

- 모든 기록은 브라우저 `localStorage`에 저장되는 데모 데이터이며 서버로 전송되지 않습니다.
- 훈련·경기·목표·메모·팀 추가, 공개 범위 변경, 보고서 CSV 다운로드를 체험할 수 있습니다.
- 학부모 계정으로는 성장 피드에 응원글을 남기고 코치에게 요청을 보낼 수 있습니다. 코치 계정에서 해당 요청을 확인·완료 처리하면 학부모 화면의 상태가 갱신됩니다.
- 학생 홈페이지 상단 프로필은 Volleybox 선수 페이지를 참고한 카드형 레이아웃입니다. 어두운 커버 위에 큰 원형 인물 사진과 이름·소속·액션 버튼을 배치하고, 그 아래에 개인 프로필(기본 정보·활동 이력·공개 범위)이 이어집니다.
- 히어로 배경은 학생이 올린 사진·영상으로 채울 수 있습니다. 사진은 최대 1280px JPEG, 영상은 2MB 이하로 자동 처리되며, 업로드한 미디어 위에는 어두운 스크림을 덮어 텍스트 가독성을 유지합니다. 삭제하면 기본 다크 그라데이션 배경으로 돌아갑니다.
- 동그라미 안 인물 사진은 `images/player-haram-portrait.png` 정면 초상으로 고정됩니다. 배경 미디어를 올리거나 삭제해도 아바타는 바뀌지 않습니다.
- 학부모·코치 계정은 히어로 배경·초상을 열람만 합니다. 갤러리는 학생·학부모·코치 모두 사진·동영상과 댓글을 남길 수 있고, 삭제는 본인 게시물만 가능합니다.
- 기본 커버 사진 `images/player-haram-game.jpg`와 정면 초상은 데모용으로 제작한 이미지이며 실제 인물이 아닙니다.
- 아카데미 데모는 5개 팀·82명 선수로 시작하며, 팀을 추가하면 선수와 통계가 함께 갱신됩니다.
- 관리자 콘솔은 회원 30명(학생 14·학부모 7·코치 5·아카데미 4), 최근 6개월 입금 내역, 공지 5건, 문의 6건, 활동 로그 시드로 시작합니다. 회원 추가·입금 상태 변경·공지 작성·문의 처리·설정 저장은 모두 브라우저에 남습니다.
- 초기 상태로 되돌리려면 브라우저 개발자 도구에서 해당 사이트의 저장 데이터를 삭제하거나 시크릿 창에서 다시 접속하세요. 관리자 콘솔의 `사이트 설정 → 데모 데이터 초기화`를 사용해도 됩니다.

## 디자인·기술 메모

- 순수 HTML/CSS/JavaScript로 구현했으며 프레임워크나 차트 라이브러리를 사용하지 않습니다.
- 차트는 CSS 막대, 인라인 SVG 라인, `conic-gradient` 도넛으로 표현합니다.
- 모바일(≤720px), 태블릿(≤980px), 데스크톱 레이아웃에 대응합니다.
- 관리자 보고서와 선수 명단, 운영 콘솔의 회원·입금·훈련 데이터는 UTF-8(BOM) CSV로 내보냅니다.
- 접근성을 위해 역할 탭, 모달, 드로어에 ARIA 속성과 키보드 조작을 적용했습니다.
- `manifest.json`과 Service Worker를 이용해 홈 화면에 설치하는 PWA를 지원합니다. 관리자 로그인·콘솔 화면도 프리캐시에 포함됩니다.

## 앱(PWA)으로 설치

- Service Worker는 **HTTPS 또는 localhost**에서만 동작합니다. 휴대폰에서 설치하려면 HTTPS 배포가 필요합니다.
- **Android·Chrome**: 주소창의 설치 아이콘 또는 랜딩 화면의 `앱으로 설치` 버튼을 누릅니다.
- **iOS·Safari**: 공유 버튼 → `홈 화면에 추가`를 선택합니다.
- 첫 방문 후 HTML·CSS·JS·아이콘이 캐시되어, 오프라인에서도 방문한 화면과 `offline.html`이 열립니다.
- 정적 자산을 수정해 배포했다면 `sw.js`의 `VERSION` 값을 올려 새 캐시를 배포하세요. 버전을 올릴 때는 단일 원장 모듈 `js/demo-data.js`가 프리캐시에 포함되어야 합니다.
- 새 버전이 준비되면 앱 하단에 `새로고침` 안내가 표시되며, 사용자가 눌렀을 때 새 버전으로 전환됩니다.
- 설치된 앱은 브라우저 주소창 없이 `standalone` 모드로 실행됩니다.
- localStorage 기록은 기기별로 저장되며, 앱 삭제·브라우저 저장 데이터 삭제 시 함께 사라집니다.
- 푸시 알림, 실제 인증, 서버 동기화, 사진·영상 서버 업로드는 아직 포함되지 않습니다.
