학생·학부모 코치 아카데미·연맹 서비스 흐름 기능 매트릭스
01

학생 · 학부모 페이지

선수는 기록하고, 학부모는 과정을 확인하고 응원합니다. 개인 홈페이지는 공개 범위를 직접 통제하는 성장 포트폴리오입니다.

개인 프로필 훈련량 경기·성장 학부모 리포트
02

코치 페이지

소속 선수의 목표·훈련·경기 기록을 한 화면에서 관리하고, 기록 검증과 피드백으로 데이터의 신뢰를 만듭니다.

선수 목록 목표·달성률 피드백 통합 현황
03

아카데미 · 연맹 페이지

소속 선수와 팀을 통합 관리하고, 종목·연령대·기간별 통계와 관리자용 보고서를 자동 생성합니다.

통합 관리 통계 참여·달성 분석 보고서
04

기능 · 서비스 흐름 모식도

가입·초대부터 기록, 자동 분석, 공유·피드백, 시즌 결산까지. 하나의 데이터가 어떻게 순환하는지 한눈에 정리했습니다.

입력 플랫폼 출력 공통 기반

핵심 구조는 “한 명의 선수, 하나의 데이터 원본, 네 개의 시선”입니다. 선수·학부모·코치·기관이 각자 입력하고, 플랫폼이 자동으로 집계·검증한 뒤, 권한에 따라 다른 화면으로 제공합니다.

입력·기록 자동 분석 권한별 제공 공통 기반
  1. 01 가입 · 초대

    역할 선택, 보호자 동의, 코치·학부모 초대 링크 발송

    학생학부모코치기관
  2. 02 기록

    프로필, 훈련량, 경기 결과, 시즌 목표를 30초 단위로 입력

    30초 입력템플릿
  3. 03 자동 분석

    종목별 지표 계산, 기간별 성장률, 목표 달성률 산출

    지표 엔진검증 배지
  4. 04 공유 · 피드백

    학부모 주간 리포트, 코치 코멘트, 응원 메시지

    권한알림
  5. 05 결산 · 확장

    시즌 리포트, 진로 프로필, 기관 통계 보고서

    PDF포토북벤치마크

역할별로 필요한 데이터를 입력합니다.

코치 선수 관리 · 목표 설정 · 기록 검증 · 피드백
