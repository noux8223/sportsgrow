# 사업·앱 서비스 개발 진행 준비 정도

> 기준: 2026년 11월, 사업계획서 2-6·2-6-1·3-3-1
> 현재 위치: **TRL 2(시제품)** — 프로토타입과 제품 정의는 완료, MVP 개발은 착수 전
> 표기 원칙: `개발완료` = 산출물이 존재, `검증완료` = 내부·공개자료 기준 확인, `예정` = 협약 후 수행

## 1. 요약

| 진행정도 | 영역 | 핵심 내용 | 다음 단계 |
|---|---|---|---|
| **개발완료** | 6개 | 사업기획·제품 정의·프로토타입(4화면)·지표 정의 초안·IR 자료·기술 설계 | M2까지 지표 24/24 확정 |
| **검증완료** | 3개 | 제품 구조(내부), 시장·수익성(공개자료), 성과지표 정합성 | M1~M4 현장 검증 |
| **예정** | 9개 | 고객 인터뷰·파트너 접촉 → MVP·유료화(M3) → QA → 파일럿 → 정식 출시 → 고도화 | M1 착수 |

## 3. 표기 기준

- **개발완료**: 문서·화면·설계서 등 확인 가능한 산출물이 있는 상태
- **검증완료**: 내부 리뷰 또는 공개 자료로 사실관계를 확인한 상태 (외부 고객 검증과 구분)
- **예정**: 협약 후 12개월 내 수행하며, 완료 판정은 기능 체크리스트·QA 결과서·계약서·로그로 함

> 정직한 표현: "앱이 완성됐다"가 아니라 **"작동하는 프로토타입과 제품 정의가 있고, 이제 개발 리드를 붙여 MVP를 만든다"** 는 단계입니다.
