## 1. 설계 원칙 — 이 로드맵이 지키는 5가지

| # | 원칙 | 이유 | 숫자로 |
|---|---|---|---|
| ① | **매출보다 입력률** | 기록이 안 쌓이면 리포트도, 진학도, 데이터도 없다 | 입력률 30% 미달이면 매출 목표를 버린다 |
| ② | **국가는 게이트로만** | 동시 진입은 자본 10배·규제 10개국을 요구한다 | 36개월까지 해외 매출 10% 이하 |
| ③ | **채용이 곧 자금 계획** | 총비용의 46%가 인건비. 사람을 늘리는 달이 곧 소진하는 달 | 인원 3→5→8→14→25 |
| ④ | **5년차 흑자, 7년차 자립** | 무한 소진 구조는 투자도, 사업도 지속되지 않는다 | OCF +11.78억 (Y5) |
| ⑤ | **모든 연차에 킬 스위치** | 계획은 틀린다. 중요한 것은 **틀렸을 때 멈추는 규칙** | 게이트 8개 + 중단 기준 |

> **한 문장** 이 로드맵은 "더 많이 하는 계획"이 아니라 **"더 늦게 하는 계획"** 이다. 미국은 6번째, 중국은 라이선스만, 6종목은 4년차다. 늦추는 대신 각 단계의 성공 확률을 높인다.

## 2. 연차별 계획

### 2-1. Y1 — 증명 (M1~12, 2027)

**한 줄** 야구 1종목으로 "코치가 입력하고, 학부모가 리포트를 연다"를 확인한다. **매출은 M3부터 작게 시작해 M12에 월 940만 원까지 올린다.**

| 구분 | 내용 |
|---|---|
| **시장** | 한국 (야구 아카데미·클럽) |
| **제품** | v0.1 프로필·기록(M2) → v0.5 개인홈·주간 리포트·**유료 베타(M3)** → v0.9 코치·기관(M6) → v1.0 결제·정식 출시(M9) |
| **고객** | 파트너 100곳 · 유료 선수 300명 · 코치 150명 · 아카데미 30곳 |
| **매출** | **0.3억** (M3 유료 베타 개시, M12 월 940만 원 러닝레이트) |
| **비용** | 2.95억 (Phase 0 1.13 + Phase 1 6개월 1.82) |
| **조달** | Seed 3억 (M1) + 정부출연 0.7억 (M1) |
| **인원** | 3명 → 5명 (M7 디자인·사업 각 1명) |

**핵심 과제 5**

1. 코치 20명·학부모 30명 인터뷰 → 페인 포인트 빈도표 (M2)
2. 야구 지표 24개 정의서 확정 — 타율·출루·장타·OPS·구속·회전수 (M2)
3. **입력 30초** 달성 — 경기 후 1화면 입력, 코치 일괄 입력 (M5)
4. 주간 리포트 열람률 60% — 카카오 알림톡 (M7)
5. 파트너 100곳 = **"선수 30명 등록" 조건부 무료** (M12)

**게이트** G1 (M6, 입력률 30%) · G2 (M12, 파트너 100·유료 300)

> **Y1의 성공은 매출 0.3억이 아니라, M12 시점에 "다음 달에도 쓰는 코치"가 100곳 있다는 것이다.**

### 2-2. Y2 — 반복 (M13~24, 2028)

**한 줄** 같은 제품을 **3종목·아카데미**로 넓혀, 한국에서 **반복 가능한 매출 공식**을 만든다.

|---|---|
| **시장** | 한국 (수영·육상 추가) + 일본 PoC 준비 |
| **제품** | v1.5 3종목 · 아카데미 플랜 · 벤치마크 베타 · 일본어 UI |
| **고객** | 관리 선수 8,000명 · 아카데미 60곳 · 일본 파트너 5곳 (M24) |
| **매출** | **2.0억** (한국 100%) |
| **비용** | 5.38억 (Phase 1 6개월 + Phase 2 6개월) |
| **조달** | Pre-A 10억 (M12) + 정부 R&D 1.4억 (M12) |
| **인원** | 8명 (M19 개발 2명·사업 1명 추가) |

**핵심 과제 5**

1. 수영(12지표)·육상(15지표) 사전 구축 — 기록이 이미 숫자인 종목부터 (M15)
2. 아카데미 플랜 100,000원/월 — 상담 자료·기관 리포트 자동 생성 (M16)

4. 벤치마크 베타 — 동일 연령·포지션 익명 비교 (M20)

**게이트** G3 (M18, 선수 3,000·리텐션 50%) · G4 (M24, 일본 5곳)

> **Y2의 함정** 종목을 늘리면 입력 항목이 늘고 이탈이 는다. 그래서 수영·육상은 **지표 수가 적고 자동 계산이 쉬운** 종목으로 골랐다. 3종목은 "제품 확장"이 아니라 **"입력 부담 실험"** 이다.

### 2-3. Y3 — 복제 (M25~36, 2029)

**한 줄** 일본에서 **해외 복제**를, 중국에서 **라이선스 수익**을 증명한다. 해외 매출 비중은 아직 10%다.

| 구분 | 내용 |
|---|---|
| **시장** | 한국 + 일본 확장 + 중국 white-label PoC |
| **제품** | v2.0 진학 프로필 · v2.5 벤치마크 정식 · v3.0 中考体育 모드 |
| **고객** | 관리 선수 20,000명 · 일본 30곳 · 중국 계약 1건 |
| **매출** | **4.7억** = 한국 4.7 (일본·중국은 계약·PoC 단계, 매출은 Y4부터 인식) |
| **비용** | 7.12억 (Phase 2 12개월) |
| **조달** | Series A 30억 (M30) |
| **인원** | 8명 + 도쿄 2명 |

**핵심 과제 5**

1. 일본 30곳 · 유료 10곳 — 紙(종이) 리포트 필수 기능 (M27)
2. 진학 프로필 정식 출시 — 고교·대학 진학용 성장 이력서 (M30)
3. 중국 white-label 계약 1건 — 파트너가 데이터 보유, 우리는 엔진 공급 (M33)
4. 일본 법인 검토 — 연 매출 5,000만 원 도달 시 (M30)
5. **현금흐름 −2.5억 이내** — 3년차 적자를 구조적으로 축소 (M36)

**게이트** G5 (M30, 러닝레이트 4.7억·일본 유료 10곳) · G6 (M36, OCF −2.5억 이내)

> **Y3의 의미** 매출 4.7억은 작다. 그러나 이 4.7억을 **한국 한 나라에서, 코치가 입력하고 학부모가 결제하는 구조로** 만들어낸다는 사실이 Series A의 근거다. 일본 30곳·중국 1건은 Y3에 계약을 만들고 매출은 Y4부터 인식한다 — 한 나라의 단위경제를 증명한 뒤 복제한다는 순서다.

> **게이트는 "성공 축하"가 아니라 "다음 돈을 쓰는 허가"다.** G2를 못 넘으면 Pre-A를 쓰지 않고, G4를 못 넘으면 Series A를 쓰지 않는다. 이 규율이 최대 적자를 9.67억으로 묶는 이유다.
