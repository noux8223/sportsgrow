# 실현 가능성

> **작성 전제**
> - 사업기간 **12개월** (협약 후 1개월 차 ~ 12개월 차)
> - 총사업비 **1억 원** (정부지원 7,000만 원 + 자부담 3,000만 원) 가정
> - 실제 공고문의 지원 한도·자부담 비율·비목별 편성 기준에 따라 금액은 조정 필요
> - 서비스 기능은 요청된 3개 페이지(학생·학부모 / 코치 / 아카데미·연맹)를 기준으로 함
> - **화면 목업**: `../mockup.html` — 모바일 화면 10종 + 기능·서비스 흐름 모식도 + 역할별 기능 매트릭스

## 요약

주니어 선수의 기록은 수첩·엑셀·메신저·개별 앱에 흩어져 있어 **선수는 동기를 잃고, 학부모는 과정을 모르고, 코치는 같은 정보를 반복 확인**한다. 본 서비스는 이 기록을 **선수 1명의 단일 데이터 원본**으로 통합하고, 학생·학부모·코치·아카데미·연맹이 **권한에 따라 같은 데이터를 다르게 보는 구조**로 해결한다.

개발은 **6개월 내 야구 1종목 MVP → 개발 완료**, 이후 **12개월 내 파일럿 → 정식 출시** 순으로 추진하며, 1차 프로토타입은 역할 대시보드(학생·학부모, 코치, 아카데미), 운영 콘솔, 사진·동영상 갤러리, PWA가 있는 클릭 데모로 이미 구축되어 있으나 서버 계정·결제·지표 엔진은 아직 없다. 핵심 차별성은 ① 훈련량·경기기록·목표 달성을 결합한 **3축 성장 데이터**, ② 개인 홈페이지 기반 **성장 포트폴리오**, ③ 미성년자 특화 **권한·공개 범위 관리**, ④ 기관용 **통계·보고서 자동화**다.

정부지원사업비는 인건비(40%), 외주용역비(26%), 마케팅(14%), 기자재·SW(9%), 교육·여비(6%), 예비·기타(6%)로 편성하고, **분기별 마일스톤과 연동**해 집행한다. 개발 6개월에 맞춰 1단계(1~6개월)에 외주·기자재를 선집행한다.

## 1. 서비스 구체화 및 개발 계획

### 1-1. 개발 방향

| 원칙 | 내용 | 적용 |
|---|---|---|
| **입력 최소화** | 기록은 30초 안에 끝나야 지속된다 | 최소 필수 항목, 최근 값 자동 채움, 템플릿 |
| **통계 자동화** | 입력 즉시 주간·월간·기간별 통계 | 집계 파이프라인, 성장률 자동 계산 |

**개발 단계 구분**
- **MVP·유료 베타 (1~3개월)**: 학생·학부모 기본 기능 + 기록·통계 + 주간 리포트, 요금제·결제
- **2단계 (4~6개월)**: 코치 목표·피드백·통합, 아카데미·연맹 통합 관리·통계·보고서
- **QA·보안 (6~7개월)**: 성능·부하, 개인정보 영향, 백업·복구
- **파일럿·정식 출시 (7~9개월)**: 아카데미 10곳 운영, 구독 결제 고도화·정식 출시
- **고도화 (10~12개월)**: 자동 입력(OCR·음성), 벤치마크, 확장 종목

### 1-3. 시스템 구성 및 기술 스택

```
[Web / PWA]  학생·학부모 · 코치 · 기관 관리자
      │  HTTPS / REST API
[API Gateway]  인증·권한(RBAC) · 요청 검증
      │
[Application]  프로필 · 훈련 · 경기 · 목표 · 피드백 · 통계 · 리포트
      │
[Data]  PostgreSQL(원장) · Redis(캐시) · Object Storage(파일)
      │
[Batch]  주간·월간 집계 · 리포트 생성 · 알림 발송
```

| 영역 | 선택 | 이유 |
|---|---|---|
| 프론트엔드 | Next.js + TypeScript | 반응형 웹, SEO, 빠른 개발 |
| 모바일 | PWA 우선 → 필요 시 React Native | 초기 개발비 절감, 앱 수준 UX |
| 백엔드 | NestJS(Node.js) | 생산성, 모듈 구조, 채용 용이 |
| DB | PostgreSQL | 관계형 데이터·통계 쿼리 적합 |
| 캐시 | Redis | 대시보드·리포트 성능 |
| 인프라 | 국내 리전 클라우드(NCP/AWS), Docker | 개인정보 국내 보관, 확장성 |
| 알림 | 카카오 알림톡·SMS·이메일 | 학부모 접근성 |
| 분석 | 자체 이벤트 로그 + BI 도구 | KPI·리텐션 분석 |
| 보안 | TLS, AES-256, RBAC, 감사 로그 | 미성년자 데이터 보호 |

> 초기에는 관리형 서비스와 서버리스 일부를 활용해 **운영 인력 부담을 최소화**하고, 사용자 증가 시 점진적으로 분리·확장한다.

### 1-4. 데이터 표준화·지표 엔진 (핵심 개발 자산)

- **종목별 지표 정의서 v1.0**: 야구(타율, 출루율, 장타율, OPS, 방어율, 이닝 등) → 수영·육상(PB, 구간 기록) → 축구·농구·배구(출전, 득점, 어시스트 등)
- **계산 규칙의 코드화**: 지표를 하드코딩하지 않고 `지표명 / 계산식 / 필요 입력값 / 표시 단위`로 정의하여 **종목 추가 시 템플릿 등록만으로 확장**
- **연령·포지션 보정**: 또래 비교 시 연령대·포지션·경기 수를 보정
- **데이터 품질**: 필수값 검증, 이상치 탐지, 수정 이력, 코치 검증 배지
- **버전 관리**: 지표 정의 변경 시 과거 데이터 재계산 및 버전 표기

**핵심 차별점 5가지**

1. **단일 데이터 원본(Single Source of Truth)**
   선수 1명의 기록을 학생·학부모·코치·기관이 **같은 원본**으로 본다. 역할별로 화면만 다를 뿐 데이터는 하나이므로, 코치가 고친 기록이 학부모 리포트에 즉시 반영된다.

2. **훈련량 × 경기기록 × 목표 달성의 3축 결합**
   기존 도구는 훈련, 경기, 목표 중 하나만 다룬다. 본 서비스는 세 축을 하나의 성장 곡선으로 연결해 **"왜 성장했는가"** 를 보여준다.

3. **개인 홈페이지 = 통제 가능한 성장 포트폴리오**
   단순 기록장이 아니라 시즌 카드·성장 그래프·코치 코멘트가 쌓이는 개인 페이지. **항목별 공개 범위**로 미성년자 정보 노출을 통제하면서 진학·팀 선택 자료로 활용할 수 있다.

4. **기관용 통계·보고서 자동화**
   아카데미·연맹은 선수별 기록을 취합할 필요 없이 **종목·연령대·기간별 통계와 보고서**를 자동 생성한다. 학부모 상담·기관 홍보 자료로 바로 사용 가능하다.

5. **미성년자 특화 신뢰 설계**
   비공개 기본, 보호자 동의, 항목별 공개, 코치 검증 배지, 감사 로그를 **기능의 일부**로 내장했다. 이는 단순 편의 기능이 아니라 학부모가 결제를 결정하는 신뢰 요건이다.

### 2-4. 경쟁력 확보 전략

**① 데이터 표준을 먼저 선점한다**
- 야구 지표 정의서 v1.0을 코치 자문단과 함께 확정하고, **"주니어 표준 지표"** 로 브랜딩
- 연령·포지션 보정 기준을 문서화해 기관·연맹과 공유
- 지표 정의서 자체를 콘텐츠·영업 자료로 활용

**② 코치·아카데미의 워크플로에 깊숙이 들어간다**
- 선수 등록 → 목표 설정 → 훈련 과제 → 기록 확인 → 학부모 상담이 **한 화면**에서 끝나도록 설계
- 코치가 매주 쓰는 도구가 되면 전환 비용이 발생 (기록·메모·리포트가 누적)
- 아카데미에는 기관 보고서·브랜딩 페이지를 제공해 **원장의 홍보 니즈**를 직접 해결

**③ 학부모 초대를 성장 루프로 만든다**
- 선수가 학부모를 초대하면 주간 리포트가 자동 발송
- 학부모의 응원 메시지가 선수 화면에 표시되어 **정서적 보상** 제공
- 시즌 결산 카드·포토북으로 **재구독·구매 명분** 확보

**④ 가격을 역할별로 분리한다**
- 학부모 3,000원/월: 커피 한 잔 이하, 부담 없는 진입
- 코치 30,000원/월: 선수 1명당 1,500원, 시간 절약 대비 합리적
- 아카데미 100,000원/월~: 학부모 상담·홍보 비용 대체
- 연간 결제 할인(36,000원)으로 현금흐름·리텐션 확보

**⑤ 신뢰를 제품화한다**
- 비공개 기본, 보호자 동의, 항목별 공개, 국내 서버
- 코치 검증 배지, 수정 이력, 접근 로그
- ISMS·개인정보보호 인증은 **2년차 목표**로 단계적 준비
- 사고 발생 시 즉시 공지·복구하는 운영 원칙 문서화

**⑥ 파트너 생태계를 구축한다**
- 아카데미 100곳(파일럿 10곳 → 확장)
- 종목별 협회·연맹과 공식 기록 연동 협의
- 훈련센터·스포츠 의학·용품 브랜드와 제휴 (측정회·콘텐츠)
- 지자체·체육회 B2G 사업으로 규모 확보

**⑦ 지식재산과 인증을 확보한다**
- 상표 2건(서비스명·슬로건), 특허 1건(권한 기반 선수 기록 공유·검증 방법) 출원
- 소프트웨어 저작권 등록
- 2년차 GS인증·ISMS 준비

**⑧ 확장 순서를 통제한다**
- 1차: 야구(지표 풍부·아카데미 시장 큼)
- 2차: 수영·육상(객관 기록·자동화 용이)
- 3차: 축구·농구·배구(팀 지표)
- 6종목 동시 개발로 인한 집중력 분산을 방지

### 2-5. 진입장벽과 복제 대응

| 장벽 | 형성 방법 | 복제 난이도 |
|---|---|---|
| **데이터** | 시즌 누적 기록·리포트·코치 메모 | 높음 (시간 필요) |
| **네트워크** | 코치 → 선수 → 학부모 초대 구조 | 높음 (양면) |
| **워크플로** | 코치의 주간 업무에 내재화 | 중~높음 |
| **신뢰** | 검증 배지·감사 로그·보호자 통제 | 높음 (사고 이력) |
| **표준** | 지표 정의서·연령 보정 기준 | 중 (선점 효과) |

**경쟁사가 복제할 경우**
- 팀 운영 앱은 개인 일상 기록·학부모 감성 경험이 우선순위가 아니다.
- 학원 CRM은 결제·출석 중심이라 성장 데이터로 전환하기 어렵다.
- 협회 시스템은 공식 대회 중심이라 매일의 훈련 기록을 다루지 않는다.
- therefore **"개인 성장 + 3자 연결"** 영역은 당분간 비어 있다. 이 틈을 2년 내 데이터·파트너로 메운다.
