시장은 크기가 아니라 순서로 나눈다

스포츠 그로우의 PAM·TAM·SAM·SOM·RAM·LAM 설정안 — 글로벌 44조 4,150억, 중국·일본 4조 9,338억, 국내 전체 2,083억, 국내 야구·축구 417억, 12개월 실행 42억. 각 계층은 진입 순서를 나타낸다.

PAM 별도 산정 전 TAM 44조 4,150억 SAM 4조 9,338억 SOM 2,083억 RAM 417억 LAM 42억
01

네 개의 원 + 두 계층 — TAM 안에서 SAM과 SOM은 형제, RAM은 SOM의 부분집합, LAM은 RAM의 10%

원의 크기는 개념도이며 실제 면적 비율이 아니다. 정확한 비율은 02의 표를 따른다.

왜 SOM이 SAM 안에 없나 — 일반적인 동심원은 SOM ⊂ SAM(부분집합)을 전제한다. 우리는 시장을 크기가 아니라 진입 순서로 나눴다. 따라서 SAM ⊂ TAM, SOM ⊂ TAM, SOM ⊄ SAM이다. 국내와 중국·일본은 모두 글로벌 시장의 부분집합이지만, 서로는 형제다. PAM은 이 모두를 포괄하는 잠재 시장으로, 현재 매출 계획에서는 제외한다.
RAM이 추가된 이유 — SOM 2,083억은 "국내에서 운동하는 청소년 전원"이라 실제 영업 대상이 아니다. 우리가 지표를 만들 수 있는 종목은 야구와 축구이고, 그 두 종목의 주니어 선수가 RAM 417억이다. RAM은 SOM의 부분집합, LAM(12개월 실행 범위)은 다시 RAM의 부분집합이다.

03

설정 원칙 3개 — 숫자가 흔들리지 않게

시장 규모는 "얼마나 큰가"보다 "무엇을 세었는가"가 중요하다. 세 원칙을 문서 전체에 동일하게 적용했다.

원칙 01
상한은 인구 × ARPU로 통일
발표기관의 전체 시장(학원비·용품·대회비 포함)과 우리 구독 매출을 섞지 않는다. 계층 비교는 도달 상한끼리만 한다.
원칙 02
상한은 상위 계층을 넘지 않는다
44조 < 76조 ✓, 4.9조 < 50.9조 ✓, 2,083억 < 2조 3,188억 ✓, 417억 < 2,083억 ✓. 넘으면 계산이 틀린 것이다.
원칙 03
순서는 점수가 아니라 문턱
매력도 점수(한국 83.5 · 일본 69.8 · 중국 51.3)가 아니라 선행 조건 개수로 진입 순서를 정했다. 그래서 SOM이 1단계다.
주의 — 원의 면적은 실제 비율이 아니다. 실제로는 TAM 대비 SOM이 0.47%, RAM이 0.94%라 눈에 보이지 않는다. 그래서 이 도식은 포함 관계와 순서를 보여주고, 비율은 표로 따로 제시한다. 또한 RAM의 야구·축구 20%는 종목별 등록선수 공식 통계가 없어 적용한 가정이며, 15%(312억)~25%(521억) 범위로 함께 본다.
